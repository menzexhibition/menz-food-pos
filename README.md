# MENZ 快餐店 · 项目说明

> 最后更新：2026-06-04

---

## 一、核心概念

用 AI 实时控制各档位菜品的投放节奏，把当天采购的食材在营业时间内刚好卖完，换取最多客流。

**AI 的不可替代价值：**
> 根据 POS 买单速度，动态决定 A 档招牌菜的投放节奏 — 人多就持续补，人少就暂停

没有 AI，这一步靠人工做不到 — 人眼判断客流太慢，无法精准控制出菜时机。

## 二、商业模型

### 菜品结构

| 档位 | 说明 | 定价 |
|------|------|------|
| B 档 | 自选主菜（3-4道）| ¥18 正价 |
| C 档 | 半荤素菜（3-4道）| 含在 B 档 |
| E 档 | 免费汤饭 | 不限量 |
| A 档 | 广东风味招牌菜（+F3翻炒）| ¥5 加购任吃 |

每天选 2 道 A 档（1 翻炒 + 1 蒸箱），A 档是营销工具/招牌菜，不是盈利主力。

### 阶梯定价

| 时段 | 价格 |
|------|------|
| 11:00-11:30 / 17:00-17:30 | ¥15 |
| 11:30-13:00 / 17:30-19:00 | ¥18（正价） |
| 13:00-13:30 / 19:00-19:30 | ¥16 |
| 13:30-14:00 / 19:30-20:00 | ¥14 |
| 14:00-14:30 / 20:00-20:30 | ¥12 |
| 14:30-15:00 / 20:30-21:00 | ¥10 |
| 15:00+ / 21:00+ | 赠送（公益餐） |

**目的：削峰填谷，引导错峰，不是吸引老人走出家门。**

### 采购上限

**¥2,000/天**（固定采购上限，不是按人头浮动）

目标是尽量用完这 ¥2,000 的食材，同时不浪费。

## 三、赠送策略

**赠送对象不限于居委会，可以是：**
- 快递小哥、外卖员（高流动性，传播广）
- 环卫工人（固定时间，存在感强）
- 附近上班族（潜在转化）
- 居委会/街道（社区关系）

**赠送的量由 AI 决定**（根据客流情况和剩余库存综合判断），不是固定数量。

## 五、AI 动态出餐系统

### 核心输入
**POS 买单速度**（不买传感器，靠收银数据）

买单间隔短 → 人多；买单间隔长 → 人少。

### AI 介入逻辑

#### A 档出菜节奏控制（核心 AI 决策）

> A 档 = 广东风味招牌菜，成本高，必须 AI 控制投放节奏

| 客流情况 | 判断 | AI 动作 |
|---------|------|---------|
| 买单不停 | 客人持续进来，人多 | F3 持续炒，A 档不断补（每批 10 人份）|
| 买单稀疏 | 客人断断续续，人少 | 暂停 A 档，等客流恢复再放 |
| 客流恢复 | 买单速度回升 | 重新开始放 A 档 |

**AI 决策的是：下一批 A 档什么时候投放，不是投多少。**

每批 A 档固定 10 人份，不能拆分。控速度 = 控时间间隔。

#### 其他 AI 任务

| 任务 | 说明 |
|------|------|
| 阶梯定价自动切换 | 时间到达，自动切价格，无需人工操作 |
| 告警提醒 | 某个菜预计还能撑10分钟，提醒后厨准备下一批 |
| 补菜计划 | 根据历史消耗速度，提前安排下一批菜的备料时间 |

### 系统约束
- **不依赖传感器**，全部靠 POS 数据驱动
- 所有菜品按 10 人份生产/投放，不能拆分份量
- AI 是大脑，员工是执行手，AI 下指令，员工执行

## 六、POS 实时出菜指令系统

### 系统架构

```
买单（POS）
  → AI 决策引擎
    → 后厨电视（分3屏）
      → 厨师照做
```

### 数据流

| 环节 | 内容 |
|------|------|
| POS 记录 | 每笔买单：时间、菜品、数量 |
| AI 计算 | 买单速度、各档位消耗速度 |
| AI 决策 | 下一批炒什么菜、哪台 F3 |
| 电视显示 | 机号 / 该炒什么 / 目标时间 |

### 后厨电视分屏示意

```
┌─────────────┬─────────────┬─────────────┐
│  F3 一号机  │  F3 二号机   │  F3 三号机  │
├─────────────┼─────────────┼─────────────┤
│  当前：     │  当前：     │  当前：     │
│  蒜蓉菜心   │  姜葱牛肉   │  四季豆肉末 │
│             │             │             │
│  下一道：   │  下一道：   │  下一道：   │
│  苦瓜牛肉   │  香菇滑鸡   │  — 等候中 — │
│             │             │             │
│  状态：就绪 │  状态：烹饪中│  状态：空闲 │
│  预计3分钟后│  剩余4分钟  │             │
└─────────────┴─────────────┴─────────────┘
```

### AI 决策逻辑

| 优先级 | 场景 | AI 动作 |
|--------|------|---------|
| P1 | 某个菜快没了 | 那台 F3 优先炒这道 |
| P2 | 哪台 F3 空着 | 分配下一道菜 |
| P3 | A 档菜待出 | 根据客流速度决定是否插队 |

### 厨师操作流程

1. 看电视 → 看到自己那台 F3 显示"该炒什么"
2. 备料 → 按配方准备食材
3. 投料 → 时间到，把菜放进 F3
4. 完成后 → 电视自动更新下一道指令
